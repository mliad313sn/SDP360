What this score measures — how well the site keeps up the Group IT operating routine: departmental reviews, issues closed, inspections run, PVs signed. It is not a rating of IT service quality: a busy site can score low if it skips its reviews, a quiet one can score well. Start with the two moves — the highest-value gaps you can close this month.

Reading the colours (RAG) — Green = on track · Amber = at risk · Red = off track. The shorthand under each dimension is its band: G≥8 A5–7 R<5 reads “green at 8 or more, amber 5 to 7, red below 5”. Overall score: green ≥70, amber 45–69, red below 45.

Ce que mesure cette note — la tenue du dispositif IT du Groupe sur le site : réunions départementales tenues, problèmes clôturés, inspections réalisées, PV signés. Ce n’est pas une note sur la qualité du service IT : un site très sollicité peut mal noter s’il saute ses réunions, un site calme peut bien noter. Commencez par les deux actions — les écarts les plus rentables à combler ce mois-ci.

Lire les couleurs (RAG) — Green (vert) = dans les clous · Amber (orange) = à risque · Red (rouge) = décroché. Le raccourci sous chaque dimension donne ses seuils : G≥8 A5–7 R<5 se lit « vert à partir de 8, orange de 5 à 7, rouge en dessous de 5 ». Note globale : vert ≥70, orange 45–69, rouge sous 45.
