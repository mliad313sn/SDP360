## Français

Rôles : editor, report-author · compte rattaché à un site. Page d’arrivée : **Accueil** (`home.html`), raccourcis du profil.

1. **Clôturer ou mettre à jour mes actions de site** — Accueil ▸ raccourci → `site-actions.html` (1 clic), puis l’action dans la page.
   - Aide : help.html#site-actions — Actions du site
2. **Saisir une inspection** — Accueil ▸ raccourci → `inspections.html` (1 clic), puis l’action dans la page.
   - Aide : help.html#inspections — Inspections
3. **Rédiger et signer le PV de réunion de département** — Accueil ▸ raccourci → `meetings.html` (1 clic), puis l’action dans la page.
   - Aide : help.html#meetings — Réunions et PV

À l’issue de la formation, la personne sait faire ces trois tâches seule. Le facilitateur ne note **aucun** résultat ici : les mesures vont dans les fiches du pilote (`T1-T8-SHEET.csv`, `SUS-SHEET.csv`).
