Lecture clé pour la réunion. Le chemin critique n'est presque jamais du dev — c'est une action côté client/tiers : clé Meraki, vue Analytics, app registration Entra, code Meridian du boss, édition SDP Enterprise. Le dev SDP est prêt ou rapide sur chaque volet ; l'ordonnancement ci-dessous se cale sur la levée de ces gates.
