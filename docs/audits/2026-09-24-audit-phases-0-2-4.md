### 1.2 Suite de tests JS — **la baseline N'EST PAS verte**

```
ℹ tests 2012   ℹ pass 1932   ℹ fail 5   ℹ skipped 75   ℹ duration_ms 26384
```

**Les 5 échecs** sont tous dans `tests/reports-editor-asset-tab.test.js` et sont **déterministes**
(reproduits en isolation) :

- `_afterSectionSaved counts the weekly strip only and needs 5 for ready`
- `showSection iterates 5 sections; autosave wires section-4`
- `submitReport warns (but allows) when the applicable tab has an empty note`
- `tab 5 has no asset lists and no Assets links`
- `tab 5 carries no « Facultatif » hint; notes not required; confirm kept`

**Cause racine — fins de ligne CRLF, pas une régression produit.** Le helper `fnSource()`
(`tests/reports-editor-asset-tab.test.js:12-17`) découpe la source de `public/reports.html` entre
`function <nom>(` et la **première occurrence de `\n}\n`**. `core.autocrlf=true` est réglé **dans la
config système ET locale** de Git ; tout l'arbre de travail est donc en CRLF
(`public/reports.html` : 8155 CR pour 8155 LF) alors que `git status` ne signale **aucune**
modification. Preuve exécutée :

```
start = 282488   end('\n}\n')     = -1       -> slice length = 0      (source extraite VIDE)
                 end('\r\n}\r\n') = 284843   -> slice length = 2358   (la vraie fonction)
```

Le produit est intact : `submitReport` est bien en `public/reports.html:4877`, son `confirm(...)`
en `4902`, sa fermeture en `4917`.

**Aggravation — mode de faux succès silencieux.** Quand l'extraction rend une chaîne vide, toutes
les assertions **négatives** du fichier (`assert.ok(!code.includes('assets.html'))`, « pas de
`<table>` », « pas de `d.lists` »…) passent **à vide**. Les garanties que ce fichier est censé
protéger ne sont donc **pas vérifiées** sur une machine Windows ; aujourd'hui la suite ne crie que
grâce aux assertions positives restantes. C'est la **deuxième occurrence** de la même classe de
défaut (les goldens e-mail, protégés depuis par `.gitattributes`, qui ne couvre que
`tests/__golden__/*.html`). Aucun autre fichier de test n'utilise cette extraction (vérifié).
