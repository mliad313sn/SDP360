## What changed

- **`public/lib/siteAliases.js` (new, UMD)** — the alias table that `services/scoreboardAliases.js` has always
  used (`hounde→HGO`, `ouaga/ouagadougou→OUA`, `dakar→DKR`, …) **moved unchanged** so the browser can reuse it;
  `scoreboardAliases.js` now re-exports it (`SB.ALIAS === SA.ALIAS`, one table). `siteFoldKey(label)`: accent/case/
  space fold → alias on the whole label, then without the generic suffix words the tracker/inspection normalisers
  already strip (`IT Agents`, `Office`, `Support`, … + `Mine`, `Site`), then on the first word (the rule
  `executive-report.html`'s site dropdown uses); a label that is a code (`HGO`) keeps it; an unknown label folds to
  its normalised spelling only (`LONDON`/`London` → `london`, never guessed into another site).
- **`public/lib/dashboard-shared.js`**
  - `resolutionSla(rows, {definition})` — the ONE helper: denominator = `isClosed` tickets (cancelled closed tickets
    stay in, never "missed" — the tile's rule), violated = closed AND missed under the definition
    (`due_vs_resolved` = `isResOverdue`, today's page rule; `flag` = stored Overdue Status, cancelled never missed —
    the server's `flag` rule). Vocabulary = `helpdesk_sla_definition`. `HD_SLA_DEFINITION = 'due_vs_resolved'`.
  - `periodSlaRates(rows, opts)` (trend) now reads `resolutionSla` — **defect fix, ON**: it used to drop cancelled
    tickets from the denominator, so its latest point disagreed with the tile.
  - `slaRanking(rows, keyFn, {minN, labelFn, definition})` — groups by `keyFn`, runs `resolutionSla` per group
    (counts **summed**, % **recomputed**), each row carries `label` (most frequent raw spelling, ties alphabetical)
    and `variants`.
  - `helpdeskSiteFoldKey(r)` — the site ranking key (folds through `SiteAliases.siteFoldKey`).
- **`public/index.html`** — loads `lib/siteAliases.js` before `dashboard-shared.js`; `pStats` tile `slaPct` =
  `resolutionSla(rows,{definition:HD_SLA_DEFINITION}).ok_pct` (same number as before for every input: same
  denominator, same rule); `renderTrend` passes `HD_SLA_DEFINITION`; `renderSlaRanking` ranks sites on
  `helpdeskSiteFoldKey`, shows the label + "+N spellings" (spellings in the row tooltip), note says variants are one
  row; drill uses the folded key and the same definition.
- **`assets-db.js`** (asset effort leaderboard) — `_canonicalSite` still applies `EFFORT_SITE_ALIASES` first; a label
  the table does not rename now folds by case/accent/space (`HOUNDE`/`Hounde`/`Houndé ` = one row), shown under the
  most frequent spelling (`_spellingByFold`, ties alphabetical). The existing merge already **sums counts and
  recomputes** the score.

## Decisions and deviations

- **The page does not read `report_config.helpdesk_sla_definition`.** The switch's default is `flag`, but the Helpdesk
  page has always used the browser rule (`isResOverdue` ≡ `due_vs_resolved`). Wiring the page to the stored value
  would change the tile under the default — forbidden ("default behaviour of the tile unchanged"). So the three
  figures share ONE helper and ONE constant (`HD_SLA_DEFINITION`, today's rule), and the helper implements both switch
  values (tested). Pointing the page at the committee's choice is a one-line change once the committee decides.
- **Cancelled handling = the tile's** (in the denominator, never missed), also what the server's
  `getMonthlyHelpdeskHistory` does (`pending_status = 0`). Only the trend changed (defect fix).
- **Massawa** folds into SGO in the helpdesk ranking because the reused alias table says so (scoreboard rule); the
  asset effort board keeps its own `EFFORT_SITE_ALIASES`, which does not merge Massawa (G-04 decision), so that board
  only gained the case/accent fold.
- `assetLabelToCode` is unchanged (only its fold now also collapses inner whitespace) — weekly/hygiene label
  resolution is not widened by this goal. The tile's Site filter and `helpdeskSiteKey` stay raw.
