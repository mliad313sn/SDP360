## Rules (R9)
- Defaults: a mine = 24/7, two 12 h shifts from 06:00 UTC, 1 eligible person per family per shift; an office =
  business hours 08:00–17:00 Mon–Fri (listed `site_calendar` holidays not required). Editable per site × family.
- Slot status: `covered` · `gap` (reason `partial` / `no_one` / `inactive_holder`) · `unknown` · `not_required`.
  **No roster rows, or a slot outside the period the roster was entered for = `unknown`, never green.**
- Eligibility reuses `governanceRoles.holderIneligible` and is ALWAYS applied here: inactive accounts and accounts
  that no longer hold the site never count (admin tier = unscoped, counts anywhere). No account state → nobody counts.
- Scope (`services/userSites.js`): reads = own sites (admin tier: all; `?site=` outside scope → 403). Writes / import =
  admin tier holding the site (super_admin, a site-less central admin-tier account, or an admin-tier account with the
  site among its sites). Import: dry run by default (rows + per-row errors: unknown site/user/family, bad times,
  end ≤ start, > 7 days, duplicate line, site not yours); `?apply=1` refused while any error remains; re-import adds 0.
- CSV: header-driven (any order, case/space/underscore-insensitive names), BOM stripped, quoted fields (shared
  `reconcileImport.parseCsv`). Times without offset are UTC.
