## Deviations
- Tests were written alongside the code, not strictly before it (the engine test was run red once on the server-rule
  denominator before the fixture was corrected).
- Only helpdesk tickets and changes have a real-data reader for preview/shadow; inspections, meeting issues and assets
  are definable and previewable on sample rows. **Follow-up:** readers for those datasets; enforced consumption for
  other screens (server readers `getCalendarMonthlyHelpdesk` / `getMonthlyHelpdeskHistory`, exec decks, metric
  registry resolve) — today only the Helpdesk page tile / ranking / trend read the adopted policy.
- No site class (mine / office) exists in the data model: per-class thresholds apply only when the shadow request
  names the site classes (`site_classes`); the site report screens do not use them yet.
- A policy that the page helper cannot express (e.g. the calendar-reader rule with the NULL-flag exclusion) leaves the
  page on today's rule; `effective` says so in `note`.
- No nav entry (per-role nav budget); direct URL `/kpi-builder.html`.
