# G02 — Cross-site / cross-department data authorization

## Audit (independent reviewer, read-only)
Site scoping is central (`services/userSites.js`, `server.js` read guard `_REPORT_ID_READ`/`_SITE_ID_READ`, write guard
`_authorizeReportWrite`, module guards) and proved by ~12 suites incl. `tests/authz-route-matrix.test.js`,
`cross-site-read-sweep`, `cross-site-write-sweep`, `cross-site-object-writes`. Session revocation is immediate
(`tests/access-revocation.smoke.test.js`). Share links: hashed, expiring, revocable (`tests/export-share-boundary`).
