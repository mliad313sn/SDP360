Date: 2026-11-04 · Branch `goal/b-01`

## What changed
- `public/vendor/` — byte-for-byte copies from `npm pack` tarballs (tarball sha512 = registry `dist.integrity`,
  recorded in `public/vendor/VENDOR.json` with each file's SHA-256), licence file alongside each:
  - `chart.js/4.4.1/chart.umd.js` (+ `LICENSE.md`) — `package/dist/chart.umd.js` (the npm UMD build is the minified one)
  - `chartjs-plugin-datalabels/2.2.0/chartjs-plugin-datalabels.min.js` (+ `LICENSE.md`)
  - `react/18.3.1/react.production.min.js`, `react-dom/18.3.1/react-dom.production.min.js` (+ `LICENSE`)
- 17 pages repointed (index, analytics, assets, dashboards, executive, executive-report, infra-health,
  inspection-actions, inspections, meetings-actions, meetings-insights, reports, site-awareness, site-report,
  system-logs, wan, activity-tracker). One Chart.js version everywhere: 4.4.1 (was 4.4.0 on 15 pages).
  `injectAssetVersion` adds `?v=` to the new relative URLs, so they get the immutable cache.
- CSP: `services/sessionAuth.scriptSrc` (non-strict pages) and the tracker override in `server.js` no longer list
  cdnjs/jsdelivr/unpkg; `connect-src unpkg.com` removed from the tracker; global `style-src` drops the two CDNs
  (nothing loads CSS from them; Google Fonts stays — fonts out of scope). `'unsafe-eval'` + CDNs remain only on
  `/dashboard-preview/` and `/design-system/`.
- Licence inventory: `tools/release/licence-inventory.js` + regenerated `LICENCE-INVENTORY.csv` record the three
  libraries as vendored with exact versions.
