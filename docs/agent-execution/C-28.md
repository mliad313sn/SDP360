## Deviations / limits

- The page gate is client-side (auth.js reads the CACHED UI policy, refreshed by `/auth/me`): right after a flip, a report-author's first visit may still be refused until one page load refreshes the cache. The server routes read report_config on every request.
- `/api/tracker/load` (tracker slides of the deck) and `/api/cache/clear` were NOT widened: a report-author without admin/tracker role gets the deck without tracker data (the deck already degrades to "tracker data unavailable"). `/api/ai/analyze`, `/api/save-pptx`, `/api/executive-new-pptx` already admit report-author.
- The C-17 shadow comparator knows the static floor (`admin`) only; a widened report-author is not logged as a divergence.
- The brand "home" link still lands executives on `executive.html` (landing belongs to `ui_role_landing`).
