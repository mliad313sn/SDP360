## Design notes
- **Switch choice:** none. Both visuals are pure additions below the existing charts; no existing number,
  tile, chart, export or behaviour changes. Judged acceptable per the goal text ("pure additions … acceptable without one").
- **Null ≠ 0:** a site with 0 assets shows "—"/"not measured" in every bullet; non-numeric Pareto counts are
  dropped into `unmeasured`, never counted as 0; zero anomalies → `ZERO` state with null percentages.
- **Bands** reuse the thresholds the Hygiene tab already applies to completeness (≥80 good, ≥50 mid) — no new threshold.
- **Pareto semantics:** kinds overlap (one asset can lack owner AND cost), so percentages are shares of flagged
  occurrences, not of assets; the note under the chart says so. A Pareto bar drills `drillHygKind(kind)` = the same
  list as the tile, so bar = tile = drill.
- **Accessibility:** Pareto canvas gets `ChartTable.attach` (role=img, aria-label, `<details>` data table) from
  `lib/charts.js`, colours from `ChartTheme`; the bullets are an HTML `<table>` with caption, scoped headers, and
  `role="img"` + aria-label per bullet with the value also printed as text.
- **Money (G-11):** nothing monetary is read or shown; `bulletHtml` is asserted free of "$".
