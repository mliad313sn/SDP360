## Deviations
- Tests were written alongside the code rather than strictly before it.
- Switch name: the governance policy is `handoffs.queue_receivers` (the policy registry is the "governance." surface; check-IAM names it so).
- Queue family for escalations is fixed to `site-it-support` (R9 family); a handoff cannot yet be ADDRESSED to a queue (needs a column outside 060/062).
- A scoped deputy with no item context does not count (fail closed): meetings (`routes/governance.js`) still read deputies without context, so a scoped deputy cannot lead a meeting session; unscoped deputies are unchanged.
- No shift-handover events table: decisions are on the row (decided_by/at, acting_for) + `system_log`.
- An incoming person who is also a deputy of the outgoing person cannot accept (SoD) — name another person.
- No `_shell` nav change; the section lives on `/coverage.html`.
