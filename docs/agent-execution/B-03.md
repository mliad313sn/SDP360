# B-03 — Trust label on pilot KPIs (certification state + data date)

Branch `goal/a-17a` (same lane as A-17a, which touched the same `index.html` region). Date 2026-11-04.

## What was built
- `public/lib/trustLabel.js` (UMD, browser + Node): reads `GET /api/metrics/registry` **once per page**,
  decorates every element carrying `data-metric-key` with a focusable label (`tabindex=0`, `role=note`,
  full text in `title` + `aria-label`). Visible text: `Non certifié · données au <date UTC>`; full text:
  `Non certifié · <certification> · <source> · <formule> · données au <date>`. Null/0/garbage date →
  « date inconnue » (EN: "date unknown"); key absent from the registry → « absent du dictionnaire des
  indicateurs »; registry not readable → « Certification non lue » — never « Certifié ». « Certifié » only when the
  row has `approved_at` AND its certification text does not say "not certified" (none does today).
  Language = shared `sdp_lang` preference / `I18nText` / browser language, like the shell.
- `public/index.html`: the 8 KPI tiles carry keys (4 map to registry metrics: `helpdesk.inbound`, `.closed`,
  `.first_reply_sla_pct`, `.resolution_sla_pct`; the 4 timing tiles have unregistered keys and say so). The footer
  that printed **the browser clock** (`'Data as of '+new Date()` at load, today's date at boot) now prints the
  **data date** from `/api/cache/status` `ts` (last successful requests sync), or « date unknown ».
- `public/site-report.js` + `.html`: every `kpi()` tile is tagged (10 registry keys, others `site.<label>`); each
  section carries its own data date: `server.js` `GET /api/reports/site-data` now adds
  `data_as_of: {requests, changes, assets, read_at}` from `sync_metadata` (null when never synced).
- `public/exec-view.html`: the 5 tiles carry `exec.*` keys; the label uses the summary's `data_as_of`.

## Decision (reversible engineering detail)
`exec-view` is public (no session). Its five figures are **fleet** aggregates that are **not in the metric
registry** (the registry's helpdesk readers are per-site calendar-month). Showing a registry formula there would
be wrong, so no public registry route was added (`routes/metrics.js` untouched, no new gate exemption): the page
calls `TrustLabel.init({registry:false})` and every tile reads « Non certifié · absent du dictionnaire des
indicateurs · données au <data_as_of> ». No metric definition changed.
