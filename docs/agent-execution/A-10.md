## Found on the way
- `routes/obligations.js` is mounted AFTER `express.static`, so `obligations.html` is served raw by the static
  handler (no nonce substitution, no `?v=` versioning). `routes/myWork.js` is mounted before the static handler for that
  reason. `obligations.html` itself was not changed (out of scope) — flagged for a follow-up.
- "Empty tracker cell" = an active activity whose window covers the current month with a blank or 0 value (the tracker
  stores 0 by default, so a real 0 cannot be told apart from "not entered"). Generic-engine trackers are not counted.
- "Last inspection" shows the newest dated inspection and days since; no "inspection due" rule exists, none invented.
