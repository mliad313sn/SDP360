## Evidence

- Locale rule: last `.`/`,` followed by 1–2 digits = decimal, else thousands; spaces, NBSP, U+202F, apostrophes, `$` = noise.
  `"2 250 000,00"` → 2250000 (legacy 225000000), `"12,5"` → 12.5, `"1,234"` → 1234 (as today).
- Property test: 500 random `n + c/100` × 7 shapes (en-US, fr-FR space/NBSP/U+202F, de-DE, de-CH, plain) ± sign.
- Parity: every `Purchase Cost($)` of `tests/fixtures/assets/Assets.csv` parses identically in both modes.
  Running the diff core over the whole fixture (4 money fields, 2473 assets): **0 differences**; with a candidate
  map naming the ten West-African labels, the only site without a currency is **LONDON (98 assets)**.

## Deviations

- Outliers Excel is a separate route (`/api/assets/finance/outliers/export.xlsx`) rather than an extra sheet in
  the finance export, so the default finance workbook stays byte-identical.
- The diff CLI exits 1 when it cannot read the database (exit 0 on every normal run, as specified).
- `send-asset-group` (group digest CLI) still reads only `xof_usd_rate`, i.e. today's behaviour; it will not
  follow the currency map until it is wired too (follow-up).
- `no_currency` is counted as an exclusion gate in the forecast coverage (so `eligible + Σexcluded = total`
  holds); eligibility remains independent of the rate.
