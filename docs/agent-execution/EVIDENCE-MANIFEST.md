# Evidence manifest — checksums and evidence levels

Generated by `node tools/agent/evidence-manifest.js` (`--check` fails when a sealed file changed). Do not edit by hand.
SHA-256 over the file with line endings normalised to LF.

## Evidence levels

- **code+test** — the change is in the code and named tests pass. The ONLY level an agent may claim.
- **browser-checked** — a person exercised the screen in a browser. Recorded by that person; pending until then.
- **human-accepted** — the accountable owner accepted the outcome (UAT, PO, committee). Pending until recorded.

No row below is browser-checked or human-accepted: nothing in this repository records such a check by a person.
An evidence file that says "verified in the browser" describes an agent run on a throwaway instance, which is
not the browser-checked level.
