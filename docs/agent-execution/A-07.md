# A-07 — Inspection drafts in IndexedDB, honest local-save status, no dropped queue entry

**Status:** implementation_status IMPLEMENTED · tested UNIT (node, injected fakes) + local browser check ·
field_validated / deployed / business_accepted UNKNOWN.

## What changed
- `public/lib/draftStore.js` (UMD): `makeDraftStore({adapter})` (`put` serialises synchronously and
  resolves `{ok}`/`{ok:false,error}`, never throws), adapters `idbAdapter` (database
  `em-inspection-drafts`, store `drafts` — not the `field` database auth.js wipes on logout; a quota
  error is caught as a transaction **abort**), `localStorageAdapter`, `memoryAdapter`, `autoAdapter`
  (localStorage only when IndexedDB cannot open), `migrateFromLocalStorage` (copy → read-back verify →
  remove; idempotent; never onto a localStorage fallback), `reverseCopyToLocalStorage` (rollback only),
  `describeError`.
- `public/inspection.html`: `saveCurrent` returns a Promise; `loadCurrent` is async (falls back to a
  legacy localStorage copy the migration kept); the wrapper shows "✓ Saved locally" only after a
  resolved ok, otherwise red "⚠ NOT saved on this device — <reason>. Click Save now … or export (JSON)"
  (`__inspectionSync.lastLocalError`); new/switch ask before leaving an unsaved draft and never keep the
  old state under a new id; `flushQueue` reads the store and keeps a missing draft queued (pill:
  "N unsent (draft missing on this device)"); `forceSyncNow` no longer says "safe locally" after a failed
  local save; `navigator.storage.persist()` once; pending debounce flushed on `visibilitychange`/`pagehide`;
  migration at init. Save model unchanged (no automatic server POST).

## Browser check (local static server, APIs stubbed, Chromium)
- 12 MB photo: localStorage probe throws `QuotaExceededError`, draft store save ok (IndexedDB).
- Tab closed and reopened: draft back with the 12.6 MB photo.
- IndexedDB put forced to throw QuotaExceededError: status red, class `local-fail`; Save now with
  the server down → "NOT saved on this device … · Server save failed too".
- A legacy localStorage draft was moved and its key removed on load.

## Rollback
Revert the page together with a one-off call of `DraftStore.reverseCopyToLocalStorage(store, localStorage,
'em_it_inspection_v2')` (skips and logs drafts over 4 MB). Server copies are unaffected.

## Left for a person
One field inspector fills a large inspection (many photos) offline, closes the tab, reopens it, then
clicks Save now once online.
