# SDP360 — agent execution (G00–G24)

This folder is the **single source of truth** for the remediation programme in
[`SDP360_GOALS_READY_TO_PASTE_EN.md`](SDP360_GOALS_READY_TO_PASTE_EN.md) (roadmap:
[`SDP360_ROADMAP_FR.md`](SDP360_ROADMAP_FR.md)). It supersedes `docs/sdp360/2027/00-*` and
`docs/sdp360/consolidation/09-*` as the current state; those stay as history.

| File | What it is |
|---|---|
| [`GOAL_TRACKER.csv`](GOAL_TRACKER.csv) | one row per goal, statuses backed by evidence; the only tracker |
| `Gxx.md` | evidence report for each goal (commands, results, CI links, SHAs, remaining blockers) |
| [`INVENTORY.json`](INVENTORY.json) / [`INVENTORY.md`](INVENTORY.md) | generated by `node tools/agent/inventory.js`: every page, route, job and migration with a stable id and its test references; `tests/agent-inventory.test.js` fails when it is out of date |
| `kit-examples/` | the programme kit's guard hook and settings, **copied as examples, not active** (the hook blocks `git push`, which this session is explicitly authorised to do on `claude/sdp360-consolidation`) |
| `../ai-decisions/` | ADRs for technical choices made during the programme |

Project skills and agents from the kit are in `.claude/skills/sdp-*` and `.claude/agents/sdp-*`; the boundaries are in
`.claude/rules/SDP360_BOUNDARIES.md`.

## Status vocabulary (each column needs its own evidence)

`implementation_status`: `NOT_STARTED` · `PARTIAL` · `IMPLEMENTED` · `BLOCKED`
`tested`: `UNKNOWN` · `UNIT` · `INTEGRATION_PG` · `CI_GREEN` (only after the workflows finished green on the cited SHA)
`field_validated`, `deployed`, `business_accepted`: `UNKNOWN` unless a signed record exists. **No goal in this
programme can set them from the repository.**
