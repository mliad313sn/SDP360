# C-14 — PPM visuals: risk P × I matrix, resource pressure view, Gantt keyboard + baseline legend

Closes **G22** (native PPM visuals) and the Gantt half of **F28** (keyboard on the diagrams). Additive, no switch,
no server change, no migration. Data come from the routes the pages already call
(`GET /api/governance/portfolio`, `GET /api/governance/portfolio/project/:id`), so the A-15 read scope and the G12
money rule apply unchanged; the new views show no amount (asserted).

## What changed
- `public/lib/ppmVisuals.js` (new, UMD, pure): `riskMatrix`, `resourcePressure`, and the shared renderers
  `riskMatrixHtml`, `cellListHtml`, `pressureHtml` (every value through the page's `escapeHtml`).
  - Matrix: open risks (kind `risk`), 3 × 3 on the RAID scale; a risk with probability/impact missing, 0 or outside
    1–3 goes to **Not scored**, never in a cell; `sum(cells) + not_scored = considered`. Grid of buttons (count + band
    text in the aria-label, colour never alone), click → list of that cell's risks (aria-live), same data as a table.
  - Pressure: per person (same owner key as `projectSchedule.resourceConflicts`) × week (Monday UTC), peak daily
    allocation of open tasks; > 100 % → “▲ over” + colour; task without allocation → “+N unknown” (never 0 or 100);
    effort hours spread over the task's days; unassigned / undated tasks counted under the table; long ranges capped
    (26 weeks around today, stated). List view `<details>` = table alternative.
- `public/project.html`: Plan tab — swatch legend naming the baseline actually drawn (current task baselines or the
  chosen version), Gantt bars focusable (roving tabindex, `data-task`), arrows / Home / End move, Enter / Space / click
  open the task (table row focused + editor loaded when editable), pressure panel. RAID tab — risk matrix panel.
- `public/portfolio.html`: risk matrix + pressure panels, swatch legend on the timeline, arrow keys between the
  project-key links of the timeline rows (Enter opens `project.html?id=`), keyboard hint; FR entries in
  `public/lib/i18n/portfolio.fr.js`.
- `public/help.html` §25 EN + FR: matrix, pressure, keyboard, legend, “table views are the screen-reader path”.
