# B-05 — Browser journeys in CI (Playwright, PostgreSQL 17)

Decision record: `docs/ai-decisions/ADR-B05-browser-journeys-ci.md`.

## What was built
- `tests/e2e/fixtures/server.js` — boots the real `server.js` (all PostgreSQL stores + migrations + metric
  registry) on a throwaway database (`PG_ADMIN_URL`, else a schema on `PG_URL`) and an ephemeral 127.0.0.1 port;
  bootstrap admin / API key random per run.
- `tests/e2e/fixtures/seed.js` — sites A = Hounde (HGO), B = MANA; users editor A, editor B, Group IT
  (`committee-member`), technician A (`field-tech`), random passwords; a PV with one overdue action on HGO; last
  week's report per site (via `POST /api/reports/ensure` as each editor); one portfolio project per site; a
  Friday group cadence.
- `tests/e2e/fixtures/browser.js` — Chromium contexts with every non-localhost request aborted and recorded,
  Google Fonts the only allow-listed origin (see ADR); per page: transfer bytes since navigation, DOMContentLoaded
  and load times; page errors; one JSON artefact per journey.
- `tests/e2e/fixtures/harness.js` — `runJourney()`: boot → seed → browser → steps → assert 0 unexpected
  external requests → artefact.
- Journeys (`tests/e2e/*.spec.js`), all logging in through `login.html`:
  | id | journey | proves |
  |---|---|---|
  | T1 | site editor, Site Actions, "Overdue only", status → cancelled with justification | `md_actions.status`, `status_note`, audit row with author |
  | T2 | site editor opens last week's report, helpdesk tab (site group), Submit | status `submitted`, audit `submitted` |
  | T3 | technician, field app offline: quick inspection + 1 photo queued, online → Sync | outbox empties, inspection stored for HGO with exactly 1 photo, photo rendered on `inspection.html` |
  | T4 | Group IT, Meeting Cockpit, "Prepare session" on the Friday cadence | planned session with a generated agenda, live view opens |
  | T7 | shell FR toggle (with `ui_i18n_pages='1'` in the throwaway DB), Help | page body + `<html lang="fr">`, manual opens in a new tab in French |
  | T8 | keyboard only: sign-in, first Tab = skip link (A-12a), Ctrl+K, "Portfolio", Enter | portfolio page reached without a mouse event |
  | DENY | editor A opens `reports.html?report=<B>`; portfolio with `portfolio_site_scope_reads` 0 then 1 | report never opens, API 403 (own 200); switch off lists B's project (today), switch on hides it page + API |
- `tools/test/run-e2e.js` (`npm run test:e2e`) — journeys `--runs=N`, then `tests/*-browser.test.js`; red on a
  failure, a skip, a missing artefact or any unexpected external request; `summary.json`. `--negative-control`.
- CI: new `e2e` job (PostgreSQL 17, trust auth, journeys twice, negative control, `e2e-journeys` artefact);
  Chromium installed before `npm test` in `test` (ci.yml) and in `release.yml`.
- `tests/e2e-harness.test.js` (5, in the manifest): classifier, every spec through the harness, devDependency only
  + installer `--omit=dev`, CI wiring, field-app fixes.

## Defects found by running the journeys (fixed)
1. Field app: photos never decoded on the served app (`blob:` URL vs CSP `img-src 'self' data:`).
2. Field app: on a fresh phone the site was never selected and low-bandwidth mode came up on (`tx()` returned the
   IDBRequest for a missing key). Details in the ADR. `field-storage-browser.test.js` extended; red on the old code.

## Evidence (this machine, Chromium 141 / Playwright 1.56.1, PostgreSQL 16 local cluster)
- `node tools/test/run-e2e.js --runs=2` → GREEN, 7 journeys × 2 runs, 0 fail / 0 skip; browser unit test 1 pass;
  **unexpected external requests 0** in every journey; allow-listed (Google Fonts, aborted) 1–2 per journey.
- `node tools/test/run-e2e.js --negative-control` → T1 red with the broken selector → exit 0.

  field ≈85 KB / 53–66 ms · inspection ≈282 KB / 226–261 ms · cockpit ≈218 KB / 97–133 ms · help ≈251 KB /
  360–475 ms · portfolio ≈184–187 KB / 57–143 ms. Measurement only; no threshold.

  installer-v2-static 20, field-pwa-static 2, field-storage-guard 6, field-french 4, meeting-status-options 5,
