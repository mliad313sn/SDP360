# B-07 — D-13 decision pack: dry run of every report and alert (audit P0-04, P0-07)

## What changed
- `tools/reports/catalogue-dry-run.js` (new CLI, loads `.env` first like every `tools/reports/*` CLI):
  `node tools/reports/catalogue-dry-run.js [--days=30] [--out=pack.md] [--json]`. Reads `report_config`,
  `report_recipients`, digest subscriptions, enabled alert rules and the last N days of history
  (`report_sent_log`, `sync_runs`, `sync_watermarks` alert marks, `report_runs`, `notifications`,
  `alert_firings`, `commitment_escalations`, `sla_alert_log`) inside ONE `BEGIN READ ONLY` transaction
  (one savepoint per read, always rolled back). Calls no sender. A missing table is reported next to the
  item it feeds, never fatal.
- `services/reportCatalogue.js` — read helpers only, pure (`DELIVERY`, `OTHER_SENDERS`, `effectiveConfig`,
  `directoryRecipients`, `evaluateDelivery`, `firedSummary`, `buildDryRun`, `dryRunMarkdown`). The R01–R16 /
  A01–A16 rows and `toMarkdown()` are untouched (REPORT-ALERT-CATALOGUE.md unchanged).
- Recipient rules copied from the real senders: group lists split on `,` (`decideHygieneSend`,
  `decideAssetGroupSend`); sync alerts and publish split on `/[,;\s]+/` and sync alerts are on unless `'0'`
  (`server.js` getAlertConfig); directory senders = confirmed address only via `reportDirectory.resolveFromRows`,
  inactive sites skipped, asset reminders = asset manager then coordinator (`recipientsFor`). Unconfirmed
  addresses are listed as "kept out"; `never_send_unconfirmed=0` is flagged. Webhook/Teams URLs and the Teams SLA
  channel map are secrets: only "configured" is printed, never decrypted.
- The pack's "Read this first" block names every sender that is armed but reaches nobody. With shipped defaults:
  **R11/A08 — `sync_alert_enabled`=1 while `sync_alert_recipients` and `sync_alert_teams_url` are empty: the
  alerter still stores its dedup mark, then drops the alert** (server.js getAlertConfig returns null). Also shown:
  the coordinator monthly report has no arm flag (the scheduled task is the switch), SMTP missing, STOP switch.
- Senders with no catalogue id (coordinator monthly, scoreboard, asset group, asset reminder, new-hardware alert)
  are listed so the meeting sees every outbound path.
