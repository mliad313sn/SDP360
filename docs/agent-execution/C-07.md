## What changed

- **`public/lib/chartTheme.js`** — the C-06 `ChartTable` now lives here (the theme is loaded right after Chart.js on all
  17 Chart.js pages); `lib/charts.js` re-exports the same object, so analytics/index/reports callers are unchanged.
  New **`a11yPlugin`** (`id: 'edvA11y'`, `afterUpdate`), registered once by `apply()` (`Chart.register`): every chart gets
  `role="img"`, a one-line `aria-label` summary (highest/lowest, "N not measured", "no data"), `aria-describedby` and a
  collapsible `<details class="edv-chart-table">` built from the chart's own labels/datasets. Title = `data-chart-title` →
  Chart.js title → author `aria-label` → card heading → "Chart" (kept on re-updates, never nested). The table goes after the
  sized wrapper (climbs ≤ 2 single-child parents) so Chart.js responsive sizing is not disturbed. `{x,y}` points read as y.
  Opt out per canvas: `data-chart-table="off"`; a page that calls `ChartTable.attach` itself is marked `"page"` and skipped
  (analytics keeps its own C-06 tables with units/state). Table CSS injected once (`#edv-chart-a11y-css`). Best-effort:
  never throws. **`prefers-reduced-motion: reduce` → `Chart.defaults.animation = false`** (`prefersReducedMotion()`).
- **`public/lib/charts.js`** — `TrendPanel.tableSpec(spec, title)` (pure: one row per period, volume + rate series, targets
  excluded); `render()` attaches ONE table per panel (mode `"panel"`) and marks both pane canvases `"page"` with
  `aria-describedby` → no per-pane duplicate; if the page already owns the container (analytics), nothing is added.
- **`public/lib/ppmVisuals.js`** — `navIndex(key, cur, n, {cols})`: the single keyboard model (arrows, Home/End, clamped,
  optional grid). Risk-matrix caption tells keyboard users the arrows work.
- **`project.html` / `portfolio.html`** — Gantt bars and timeline rows use `navIndex` (was two inline copies; portfolio now
  also accepts Left/Right); **new**: arrow-key navigation between the non-empty risk-matrix cells on both pages.
- **`help.html`** §3 (EN+FR): every chart has a data table + spoken summary, reduced motion honoured; §25: risk-matrix arrows.
