## Deviations from the goal text
- **Budget**: "Operations ≤ 8 for every persona" cannot hold for admin-tier with the goal's own proposal
  (portfolio, rfi plus a Configure group). Budget implemented = **≤ 8 task entries + Configure (≤ 3, admin tooling)**.
  To fit, **obligations and RFI are off the lean menu** (finder + Home/Site-Actions/Portfolio links) and cockpit /
  report studio are not shown to a plain viewer or field-tech in lean. Field app moves to Governance in lean so
  field-tech sees no Configure item.
- **Labels at 1366 px for super_admin**: `short_label` cannot recover 360 px; instead a measured fit guard keeps
  labels when they fit (editor, admin, viewer) and falls back to today's icon rendering otherwise. Full profile is
  untouched (it already overflows by ~53 px at 1200 px for super_admin — pre-existing, left for A-22).
- `_shell.css` colours/contrast untouched (A-22).
