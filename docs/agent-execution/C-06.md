# C-06 — Analytics charts: dual axis → stacked panels, shared states, token palette, aria + data tables

Goal row: plan v3 §4, wave V2. Closes F10, F18, F19 (analytics part) and F26. Builds on C-01 (`public/lib/analyticsLogic.js`).
Presentation of the same numbers only — no KPI, threshold or query changed, so no switch (defect-grade honesty).

## What changed

- **`public/lib/charts.js`** — new exported **`ChartTable`** (browser global `ChartTable`, Node `require('./charts.js').ChartTable`)
  for C-07 to reuse: `rows(spec)` (labels × datasets, units in headers, null → "—"), `summary(spec)` (one-line aria text:
  highest/lowest per series, "N not measured", "no data for this period", "Source not current", "data unavailable"),
  `html(spec)` (`<summary>Data table</summary><table>` with caption, `th scope`, every value escaped), `attach(target, spec)`
  (canvas → `role="img"`, `aria-label`, `aria-describedby`; one `<details id="<id>-table" class="edv-chart-table">` inserted after
  the chart wrap, replaced on re-render), `detach(target)` (error state). `TrendPanel.render` accepts an optional `spec.aria`
  {volume, rate} to override its two pane labels (default unchanged).
- **`public/lib/analyticsLogic.js`** — **one state vocabulary** `STATES = LOADING · VALID · ZERO · NO_DATA · STALE · ERROR` with
  `STATE_MAP` mapping each onto the existing notions (`kpiRag.rag` → `'NA'` wherever colour is not allowed; dashboardRender
  freshness `STALE`); `colourAllowed` (VALID/ZERO only), `classifyState`, `classifySeries`, `kpiCardState` (RAG only when colour
  allowed; neutral accents blue/orange only); `statusPalette(theme, stale)` (status colours ONLY from `--rag-*`, all neutral when
  stale) and `seriesColours(n, theme, alpha)` (categorical ONLY from `--chart-series-*`, lower alpha past 6). `renderSectionError`
  also stamps `data-state="ERROR"`.
- **`public/analytics.html`** — loads `lib/charts.js` (deferred, right after `chartTheme.js`); both dual-axis charts (Monthly ticket
  volume + SLA %, Monthly CSAT score + response rate) are **TrendPanel stacked panels**, one y-axis each, shared x, same data arrays,
  nulls kept as gaps; `PALETTE`/`MULTI` and every hex/11-px font/tick colour removed from the script (theme defaults apply);
  categorical charts use the series tokens, risk / CAB status / CSAT distribution use the status map; every KPI card starts
  `kpi na data-state="LOADING"` and is set through `setKpi` → `kpiCardState` (stale section: value shown, colour withheld, sub-line
  colours withheld); every chart goes through `describeChart` (card `data-state`, ChartTable attach) and a NO_DATA series draws no
  empty axes (the table says "No data for this period"); an error marks chart cards ERROR and removes their tables.

## Visible changes (presentation only, same numbers)

- Two trend charts become two stacked panels each; card subtitles say "(top) … (bottom)".
- Status colours use the RAG tokens (e.g. green `#1E7B45`, not `#1B9A3A`); single-series bar charts all use series colour 1.
- KPI cards no longer carry a decorative red/amber/green top bar (Escalated, Emergency, Backlog, Avg completion, Avg turnaround,
  Satisfied) — a status hue on a value nobody judged read as a verdict; blue accents kept. Loading/NO_DATA/STALE/ERROR cards are neutral.
- A collapsible "Data table" under every chart.
