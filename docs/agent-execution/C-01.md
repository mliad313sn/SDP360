## What changed

- **`public/lib/analyticsLogic.js`** (new, UMD, global `AnalyticsLogic`) — the page's arithmetic and colour decisions,
  side-effect free: `fmtNum`/`fmtPct` (null / non-finite → "—"), `ratioPct` (denominator guarded), `ragClass` /
  `kpiCardClass` (null → `na`), `overLimitClass`, `riskColourKey`, `approvalColourKey`, `colourFor`, `esc`,
  `miniTableHtml`, `fetchJson` (refuses non-2xx), `createLoadCoordinator`, `renderSectionError` / `clearSectionError`.
- **`public/analytics.html`** — loads the lib (non-deferred, before the inline script) and uses it at every affected
  site; adds one `#err-<section>` alert host per section, `.kpi.na`, `.freshness-badge.error`, `.btn-retry` styles.
  Thresholds are the page's existing ones (90/75 SLA, 90/70 change success, 80 CAB, 20 response rate, 80/60 CSAT) —
  no threshold invented or changed. Dual-axis charts, palette and chart tables are untouched (C-06).
