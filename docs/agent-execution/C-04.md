## Behaviour notes
- **Heatmap**: refused for NEW widgets (`PUT` → 400). A widget that already carried `heatmap` in the stored draft keeps it
  (`legacyIds`); submit/publish validate stored definitions with `allowRetired`. It renders as a table with a notice.
  Seeds use no heatmap/bar/table (checked by "existing seeds stay valid").
- **ragGrid**: a null value, a stale/never-synced source or an unrecognised rag is the grey "Unknown" cell — never green.
- **table**: columns site · value · unit · target · state; header buttons sort (not-measured always last); target = the
  same `kpiTargets.targetFor` lookup as the KPI tile (evaluated at `now`, C-05 re-anchors it).
- **trackerRag**: key `it-activity` (optionally `it-activity-YYYY`); window = the registry's tracker reader window
  (`resolveWindow('ytd', …)`), no new time anchoring; only the caller's scoped sites; no input in the period → `NO_DATA`, rows `[]`.
  CSV export carries tracker rows and the extra series lines; stale-source degrading includes the series metrics' modules.
- Single-series trend payloads are unchanged (`lines` only appears when `series[]` is set).
