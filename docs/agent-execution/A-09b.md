## Known limits (stated, not hidden)
- Exact-text swapping: strings with an embedded value (toasts like "Saved 3 cell(s)", "Error loading reports: …")
  stay English; chart titles/legends drawn on a canvas stay English.
- A data cell whose text equals a UI word (e.g. a product type "Software", a state "Expired") is translated for
  display too. Option VALUES are never touched, so nothing sent to the server changes.
- reports.html admin console (~640 strings) not translated — the audience is super_admin/admin.
- No browser in this sandbox: pages were not opened with FR selected.
