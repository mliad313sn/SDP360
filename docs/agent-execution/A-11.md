# A-11 — one published site verdict (shadow switch) + "not measured" for tracker aggregates

Decision D-03 (repo log; playbook D-1) is **OPEN**. Everything ships behind `site_score_published_model`,
default `legacy` = today. ADR: `docs/ai-decisions/ADR-A11-published-site-score-switch.md`.

## What changed
- `public/lib/kpiRag.js` — `aggregate(values, type, opts)`: opt-in `opts.emptyAs`; default empty result stays 0.
  New `isMeasured(values)`.
- `services/trackerDefinitions.js` — additive `measured` on every item (shared item: any unit entered something).
- `services/reportConfig.js` — `site_score_published_model: 'legacy'`; PILOT-PROFILE row flipped to `built`.
- `services/publishedSiteScore.js` (new, pure) — `normalizeModel`, `publishedVerdict`.
- `tools/reports/send-scoreboard.js` — programme mode computes the programme score per site (injectable
  `deps.programmeScore`; a failed read → non applicable) and passes `published` to the digest.
- `services/siteScoreboardReport.js` — programme column / relabelled headers / both windows when `published` is given;
  without it the output is byte-identical (SHA-256 pinned from the pre-change code).
- `services/reportTemplates/coordinator.js` + `services/sendCoordinator.js` — operational mode only: a labelled
  "Published site verdict" card (spread-inserted, so legacy HTML is unchanged).
- `tools/reports/site-score-shadow.js` (new, read-only CLI) — evidence pack for the committee.

## Not touched
