## Decisions (documented)
- **Partial-period comparison**: the simplest honest option — while the current period is running, the tile keeps
  the previous value but shows **"not comparable — this period is still running"** instead of a delta
  (`previous.delta=null, comparable:false`). No same-length-to-date reconstruction (would need day-grain readers).
- **Month window on a weekly trend**: the series ends on the last ISO week that finishes inside the month.
- **Partial**: a period is partial while its last day is after today; a window ending today (current/rolling) is complete as of today.
- `window_end` = end of the last period, or today while it runs. `as_of` kept as an alias of `computed_at` (CSV / field app).
- Concurrency is per widget over sites/windows (widgets stay sequential, so timing per widget is meaningful); RBAC
  scope unchanged — the same `sites` list is mapped.
